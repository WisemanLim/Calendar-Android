# impl/13 시나리오 — 메인화면 5개 버그 + 온보딩 iOS 대응

## 대상 이슈
1. 설정 화면 - 캘린더 선택 섹션 노출 보장 + 고객문의 섹션 미존재
2. 하단 미니 달력 - 월/연도 헤더 미표시
3. 하단 미니 달력 - 이벤트 수 색깔 미반영 (nextMonthGrid에 count=0)
4. 주간 스트립 - 날씨 이모티콘 미표시 (fallback 이모티콘 포함)
5. Hero 날짜 영역 - 음력 날짜 미표시
6. 레이아웃 - 하단 달력이 화면 하단에 고정되지 않음
7. 온보딩 - 개발 빌드 매회 미실행 / iOS와 다른 디자인

## 시나리오

### TC-1: 설정 - 캘린더 선택 노출
- 설정 화면 진입
- "캘린더 선택" 섹션 헤더 항상 표시됨 (권한 없을 때 안내 문구)
- 기대: 캘린더 목록 또는 "불러오는 중" 안내 표시

### TC-2: 설정 - 고객문의 섹션
- 설정 화면 스크롤 하단
- 기대: "고객문의" 섹션, 이메일 주소, 앱 버전 표시

### TC-3: 하단 달력 월 헤더
- 메인 화면 하단 두 달력
- 기대: 좌측 = 현재월 "M월 yyyy" 헤더, 우측 = 다음달 헤더

### TC-4: 하단 달력 이벤트 색깔
- 이벤트 있는 날 미니 달력에서 확인
- 기대: 이벤트 수에 따라 rainbow dot 색상 표시

### TC-5: 주간 스트립 이모티콘
- 날씨 미로드 상태: 이벤트 0개 😀, 2개 😊, 4개 🤯
- 날씨 로드 상태: 해당 날짜의 날씨 이모티콘 표시

### TC-6: Hero 음력 날짜
- Hero 날짜 영역
- 기대: "음력 N월 N일" 텍스트 그레고리안 날짜 아래 표시

### TC-7: 레이아웃 - 하단 달력 위치
- 기대: 달력이 화면 최하단에 고정, Hero가 남은 공간 차지

### TC-8: 온보딩 - debug 매회 실행
- DEBUG 빌드에서 앱 재시작
- 기대: 온보딩 화면 매회 표시

### TC-9: 온보딩 - iOS 스타일
- 기대: 다크 퍼플 그라디언트 배경, 큰 아이콘, 카드형 플래너 선택

### TC-10: 온보딩 완료 후 버전 저장
- 온보딩 완료 시
- 기대: lastSeenVersion = currentVersionName 저장
