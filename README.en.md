# WiseCalA

Native Android calendar app built with Jetpack Compose — Android port of iOS WiseCal.

> **Scaffold info**: Generated by `wise-dev-standard` plugin / profile `android-compose` / domain `ict-saas`.

## Tech Stack

| Layer | Tool |
|-------|------|
| Language | Kotlin |
| UI Framework | Jetpack Compose + Material 3 |
| Build System | Gradle (Kotlin DSL) + Version Catalog |
| Min SDK | API 26 (Android 8.0) |
| Calendar Data | Android CalendarProvider (ContentResolver) |
| Persistence | DataStore Preferences |
| Weather | Open-Meteo API (Retrofit) |
| Deployment | Fastlane (supply) |
| Distribution | Play Store internal → production |
| CI/CD | GitHub Actions |

## Prerequisites

- Android Studio (latest stable) or JDK 17+ + Android SDK Command-line Tools
- Ruby & Bundler (`gem install bundler`)
- Fastlane (`bundle install`)
- Google Play Developer account + service account JSON _(for deployment)_

```bash
bundle install
```

## Quick Start

```bash
# Build dev flavor debug and install on emulator
```

## Troubleshooting

### `make dev` — `./gradlew: No such file or directory`

Gradle wrapper not generated. Run once:

```bash
gradle wrapper --gradle-version 8.10.2
```

### `JavaVersion.parse 25.0.3` (Kotlin compiler error)

System JDK 25/26 is not supported by Kotlin 2.x version parser.
**Use Android Studio bundled JBR 21** — already set in Makefile:

```makefile
JAVA_HOME ?= /Applications/Android Studio.app/Contents/jbr/Contents/Home
```

Alternative if Android Studio is not installed:

```bash
brew install --cask temurin@17   # install JDK 17
export JAVA_HOME=$(/usr/libexec/java_home -v 17)
make dev
```

### `SDK location not found`

`local.properties` is missing (excluded by `.gitignore`). Create it:

```bash
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties
```

### `Theme.AppCompat / Theme.Material3 not found`

Verify `android.useAndroidX=true` exists in `gradle.properties`. If missing:

```bash
echo "android.useAndroidX=true" >> gradle.properties
```
